Privacy policy

Last updated: 1 November 2026

Pistach is a personal planner app built by Ben Souchet for his own use. This page explains what data it accesses, why, where it is kept and how to remove it.

Data Pistach accesses

Only from accounts the owner explicitly connects in the app:

  • Google Calendar (read and write): events from the calendars the owner enables, so they appear in Pistach; events the owner creates in Pistach are written back to the chosen calendar.
  • Gmail (read-only): sender, subject, date and the short snippet of unread or starred messages from the last days. Pistach never sends, deletes or modifies email, and doesn't store message bodies.
  • Google Drive (metadata only): names, types and modification dates of recently modified files. Pistach never reads file contents.
  • Basic profile (email address, name) to identify which account was connected.
  • Slack (read-only, if connected): messages that mention the owner and direct messages sent to the owner.
  • Tasks, reminders, events and countdowns the owner creates in Pistach.

How it is used

This data is used only to show the owner their own schedule and to prepare their morning recap: what's on today, what's overdue, what's coming up and which messages may need a reply. It isn't used for advertising, profiling, analytics or any other purpose.

To write the recap, the relevant data is processed by Claude (Anthropic) under the owner's own Claude account, at the owner's request.

Google API Services: Limited Use

Pistach's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not sold, not used for advertising, not used to train generalised AI or machine-learning models, and is not transferred to anyone except as necessary to provide the features described above to the owner.

Storage and security

  • Data is stored in a private Supabase database hosted in the European Union (Paris), protected by row-level security so it is accessible only to the owner's account.
  • OAuth tokens are stored server-side only, in a table no client can read, and are never sent to the phone.
  • All connections use HTTPS.

Retention and deletion

  • Disconnecting an account in Pistach deletes its tokens and the events imported from it.
  • Access can also be revoked at any time from Google Account → Third-party connections (or Slack → Manage apps).
  • Gmail and Drive information is read when a recap is prepared and isn't kept beyond the recap text itself.
  • Everything can be deleted on request.

Sharing

No data is sold or shared with third parties, apart from the infrastructure providers needed to run the app (Supabase for storage, Anthropic for the recap) acting on the owner's behalf.
